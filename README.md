A painfully honest — yet still polite — out-of-office email auto-reply, written as a single sentence. It admits out loud what most employees only think privately (nobody actually misses their inbox while away) and still promises every message will be answered properly, with fresh eyes.

The entry:

> I'm away until Monday, and honestly I am not missing my inbox one bit, but I will return to it with fresh eyes and answer you properly.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (UTF-8, one sentence, 135 characters). No external dependencies, no network access — the text is fixed and deterministic.
